# Tags

A **tag** is a label you put on work. Tags make things findable months later, when you
have forgotten what you called something.

## Why bother

After a few weeks you will have hundreds of tasks and files. Search helps, but only if
you remember a phrase from inside the thing you want.

Tags let you group work by what it is *about*, which is usually how you remember it.

## Adding a tag

You can tag almost anything — a task, a file, a note, a project.

- Click the tag icon and type a name.
- Type a name that already exists and C5 offers it, so you do not end up with three
  spellings of the same idea.

You can also ask for tags in plain words: "tag this as client-work and urgent."

## Managing them

The **Tags** page lists every tag you have, with:

- How many things use it
- What color it shows in
- Options to rename, recolor, or delete it

Renaming a tag updates it everywhere at once. Deleting a tag removes the label but never
the work itself.

## Choosing good tags

- **Few and broad beats many and narrow.** Ten tags you actually use beat a hundred you
  do not.
- **Pick one form and stick to it.** `invoice` or `invoices` — not both.
- **Tag by subject, not by status.** The board already tracks whether something is done.
- **Use color for meaning.** Red for urgent, blue for a client, green for finished.

## Finding things by tag

Click any tag to see everything with that label. Or combine tags with search to narrow
down — everything tagged `acme` that also mentions "renewal".

Tag filters work in [Productivity](/c5/using-c5/productivity) and
[Library](/c5/using-c5/library).

## Cleaning up

Every so often, open the Tags page and sort by usage. Tags used once or twice are
usually mistakes or duplicates. Rename them into an existing tag, or delete them.

Five minutes of this every few months keeps the whole system useful.
